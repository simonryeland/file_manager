# proba QT6 - FileManager

## build:

```bash
git clone https://github.com/simonryeland/file_manager.git
cd file_manager
qmake6 fm.pro
make
```

## clear:

```bash
make clean; rm -r build_tmp/ fm Makefile .qmake.stash
```
